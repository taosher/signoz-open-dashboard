# apps/web (embed frontend)

Standalone Vite + React18 + antd5 + echarts5 app (design doc §7, independent implementation of the same contract).

- Entry: `GET /embed/:dashboardId?...` (served as `dist/index.html` by the `EmbedController` in `apps/api`)
- Auth: in-memory `apiKey` in `src/embed/auth.tsx`, never written to localStorage; when no key is given the server falls back to the env default
- Data: always via same-origin `/api/signoz/*` (`src/api/client.ts`); for the query-semantics comparison see `third_party/PATCHES.md`
- Reference snapshot: `third_party/signoz-0.97.0/` (generated by `take-snapshot.sh` from `~/develop/open-source/signoz@v0.97.0`, read-only, not part of the build)

Local development: `pnpm dev:web` from the repo root (vite on :5173, `/api/signoz` proxied to `:8080`, requires `pnpm dev:api` running alongside).
